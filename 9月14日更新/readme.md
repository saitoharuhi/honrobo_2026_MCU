# 自己位置推定・センサフュージョンシステム 仕様書

本プロジェクトは、STM32（NUCLEO-F446RE）を制御ボードとし、複数のセンサ（OTOSオドメトリセンサ、WT901ジャイロセンサ）および計測輪（インクリメンタル式エンコーダオムニホイール）を組み合わせた高精度な自己位置推定システムです。

マイコン搭載のユーザーボタンを押すことで、ロボットの構成や運用状況に合わせた5つの異なる自己位置推定モードを動的に切り替えることができます。

---

## 1. 接続ピンおよびハードウェア構成

本システムを動作させるためのSTM32F446REのピン割り当ておよび接続先の一覧です。

### センサ・デバッグ接続
| 接続対象 | 信号名 | STM32ピン | タイマー / 通信モジュール | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| **OTOS** (オドメトリセンサ) | SCL / SDA | `B9` / `B8` | `I2C1` | 光フローセンサ |
| **WT901** (ジャイロセンサ) | TX / RX | `B10` / `C5` | `USART3` | ボーレート: 115200 |
| **PC接続** (シリアル出力) | TX / RX | `A2` / `A3` | `USART2` | ST-Link仮想COMポート (115200bps) |

### 計測輪 (エンコーダ) 接続
| 計測輪名 | 信号名 (A相 / B相) | STM32ピン | タイマー | 役割・物理配置 |
| :--- | :--- | :--- | :--- | :--- |
| **エンコーダ 1** | A相 / B相 | `A0` / `A1` | `TIMER5` | 前車輪 (4輪時の前方中点 / 3輪時の右前中点) |
| **エンコーダ 2** | A相 / B相 | `A15` / `B3` | `TIMER2` | 右車輪 (4輪時の右側中点 / 3輪時の左前中点) |
| **エンコーダ 3** | A相 / B相 | `B6` / `B7` | `TIMER4` | 後車輪 (4輪時の後方中点 / 3輪時の後方中点) |
| **エンコーダ 4** | A相 / B相 | `C6` / `C7` | `TIMER3` | 左車輪 (4輪時の左側中点 / 3輪時は未使用) |

### UI・インジケータ接続
- **ユーザーボタン (B1)**: `C13` ピン (内部プルアップ `INPUT_PULLUP` 設定、押下時に `LOW` レベル)
- **ユーザーLED (LD2)**: `A5` ピン (緑色LED、`OUTPUT` 設定)

## 2. 自己位置推定モード仕様

青いユーザーボタンを押すたびに、モードが **0 ➔ 1 ➔ 2 ➔ 3 ➔ 4 ➔ 0** の順に循環して切り替わります。現在のモードは、切り替わり時のLED（A5）の点滅回数によって視覚的に確認できます。

| モード値 | 推定モード名 | 使用するセンサ・計測輪の比率 | LED点滅回数 | 用途・特徴 |
| :--- | :--- | :--- | :---: | :--- |
| **0** | **4輪＋センサ (デフォルト)** | OTOS・WT901 70% / 4輪オドメトリ 30% | **1回** | 電源投入時の標準動作。精度と安定性のバランス型。 |
| **1** | **3輪＋センサ** | OTOS・WT901 70% / 3輪オドメトリ 30% | **2回** | 3輪オムニロボット（正三角形配置）用の融合モード。 |
| **2** | **センサのみ** | OTOS 100% / WT901 100% (計測輪不使用) | **3回** | 計測輪が完全に空転・故障した際のスリップ緊急用。 |
| **3** | **4輪のみ (純オドメトリ)** | 4輪オドメトリ 100% (センサ類不使用) | **4回** | ジャイロの磁気乱れやOTOSレンズの汚れがある場合。 |
| **4** | **3輪のみ (純オドメトリ)** | 3輪オドメトリ 100% (センサ類不使用) | **5回** | 正三角形3輪構成でジャイロ・OTOSを使わない場合。 |

## 3. 計測輪の幾何学（キネマティクス）数式

### 物理パラメータ
- **配置半径 ($L$)**: `370.0` mm (ロボットの中心から各計測輪の接地面までの距離)
- **タイヤ直径 ($D$)**: `78.2` mm
- **エンコーダ分解能 (PPR)**: `8192` (1回転あたりのカウント変化)

各エンコーダが反時計回り（CCW）の接線方向に回転したときの移動距離増分を $ds_1, ds_2, ds_3, ds_4$ と定義します。

### 3.1 4輪中点配置モデル（モード0、モード3）
四角形の各辺の中点に計測輪が時計回りに配置されている構成です。
- **前後方向移動量 ($dx_{enc}$)**: 
  $$dx_{enc} = \frac{ds_4 - ds_2}{2}$$
- **左右方向移動量 ($dy_{enc}$)**: 
  $$dy_{enc} = \frac{ds_1 - ds_3}{2}$$
- **旋回角度変化量 ($d\theta_{enc}$)**: 
  $$d\theta_{enc} = \left(\frac{ds_1 + ds_2 + ds_3 + ds_4}{4L}\right) \times \frac{180}{\pi}$$

### 3.2 3輪正三角形配置モデル（モード1、モード4）
正三角形の各辺の中点（右前 $30^\circ$, 左前 $150^\circ$, 後 $270^\circ$）に計測輪が配置されている構成です。`enc1`, `enc2`, `enc3` のデータを使用します。
- **前後方向移動量 ($dx_{enc}$)**: 
  $$dx_{enc} = \frac{ds_1 + ds_3}{2} - ds_2$$
- **左右方向移動量 ($dy_{enc}$)**: 
  $$dy_{enc} = \frac{ds_1 - ds_2}{\sqrt{3}}$$
- **旋回角度変化量 ($d\theta_{enc}$)**: 
  $$d\theta_{enc} = \left(\frac{ds_1 + ds_2 + ds_3}{3L}\right) \times \frac{180}{\pi}$$

## 4. 座標射影およびセンサ融合（フュージョン）

### 4.1 グローバル座標への変換
ローカルの移動量 $dx, dy$ から、グローバル座標の増分 $dx_{global}, dy_{global}$ への変換には以下の回転行列を使用します。
$$dx_{global} = dx \cos(\theta) - dy \sin(\theta)$$
$$dy_{global} = dx \sin(\theta) + dy \cos(\theta)$$
- **センサ使用時（モード0, 1, 2）**: $\theta$ には WT901 で計測したジャイロ角度を使用します。
- **純オドメトリ時（モード3, 4）**: $\theta$ には 計測輪のみで積算した角度を使用します。

### 4.2 状態リセット・同期処理
モードが切り替わった次のタイマー割り込み（10ms周期）の際に、直前の状態変数を以下のように自動で同期します。これにより、**モード切り替え時に自己位置 $(x, y)$ や角度 $(yaw)$ が不連続に跳んでしまう現象を完全に防いでいます。**
- `past_enc_dist1~4` を現在の値に置き換えて、切り替え直後のエンコーダ差分 $ds$ を $0$ にリセット。
- `past_maus_data_0~1` を現在の値に置き換えて、OTOSの差分を $0$ にリセット。
- `past_gyro_yaw` を現在のジャイロ角度で同期。

## 5. 出力方式と通信仕様

### 5.1 シリアル出力仕様
- **出力ポート**: `USART2` (`TX: A2`, `RX: A3`)
- **通信仕様**: ボーレート: `115200` bps, データ長: 8bit, ストップビット: 1bit, パリティ: なし
- **出力周期**: **10ms周期 (100Hz)** (非ブロッキングタイマーによる制御)

### 5.2 送信フォーマット
人間およびROSノードで解析しやすい以下のASCII形式のテキストデータが出力されます（小数点第3位まで表示）。
```text
X: [X座標値] mm, Y: [Y座標値] mm, Yaw: [角度値] deg (Mode:[モード番号])\r\n
```
**出力例 (モード0の場合):**
```text
X: 125.450 mm, Y: -50.123 mm, Yaw: 45.200 deg (Mode:0)
```

## 6. 自己位置リセット関数

スタート前の位置合わせや、壁当て等で自己位置を強制的に補正するための関数が `main.cpp` 内に実装されています。外部プログラムやメインの処理からこれを呼び出すことで、座標とセンサ過去値を安全に再同期できます。

```cpp
void reset_self_position(float x, float y, float yaw);
```
- **x**: 補正後のX座標 (mm)
- **y**: 補正後のY座標 (mm)
- **yaw**: 補正後の角度 (度)。`-180.0` 〜 `180.0` の範囲外を指定した場合は、角度の補正（ジャイロ初期化）を行わず位置のみを変更します。
